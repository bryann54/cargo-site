# Tested & Trusted identity

## Concepts

1. **Customs mark / T monogram** — a framed initial with a final amber registration tick reads as an accountable mark of completion without imitating official customs seals.
2. **Container corrugation** — short parallel divisions in the lower stem recall ordered container ribs and give the T a cargo-specific construction.
3. **Route handoff** — the offset amber tick meets the terminal stroke to suggest a deliberate origin-to-destination handoff.

**Recommendation:** use the combined container-line T mark and wordmark. It remains calm and readable at small sizes, while the restrained amber detail is distinctive without making the identity feel like a generic logistics logo.

## Files

- `logo-horizontal.svg` — primary horizontal lockup for site headers and documents.
- `logo-stacked.svg` — centered lockup for square applications.
- `logo-symbol.svg` — square mark for app tiles and avatars.
- `logo-mono-dark.svg` — one-colour deep teal for light backgrounds.
- `logo-mono-light.svg` — one-colour white for dark backgrounds.
- `logo-reversed.svg` — teal/paper reversed lockup for deep teal panels.
- `favicon.svg` — simplified square symbol for browser tabs.
- `brand-sheet.svg` — vector one-page identity reference; export to PNG for raster delivery.

## Palette and type

- Primary teal: `#0f766e`
- Deep teal: `#0f2b2c`
- Warm accent: `#d97706` (small detail only)
- Warm paper: `#f6f3ec`
- Display face: Lora Variable, self-hosted from Fontsource, SIL Open Font License.
- Text face: Manrope Variable, self-hosted from Fontsource, SIL Open Font License.

## Use rules

- Construction grid: 96 × 96 units; 4-unit primary strokes; 17-unit frame radius.
- Clear space: reserve at least one mark-stroke width on every side.
- Minimum size: symbol 16 px; horizontal lockup 228 px wide. Prefer symbol-only below 120 px.
- Use the teal lockup on paper or light surfaces and the reversed mark on deep teal. Do not stretch, add gradients/shadows, recolour arbitrarily, or place over busy imagery without a clear field.

## Quality checks

- Silhouette test: framed T and divided stem remain distinct when reduced.
- 16 px test: the border, T crossbar, stem, and short amber terminal remain individually recognizable; fine stroke detail naturally softens at 16 px.
- One-colour test: the geometry is preserved in both dark and light monochrome variants.
- Light/dark test: the primary lockup is intended for paper; reversed lockup for deep teal.

## Production note

These SVGs are original concept marks and use live licence-safe system font stacks rather than outlined lettering, because no vector-outline font conversion tool is available in this workspace. Before large-scale print, convert the wordmark text to paths and review optical kerning with a brand designer. Raster export files (favicon PNG, Apple touch icon, 512 icon, OG and brand sheet PNG) are not included yet; keep this SVG set as the source of truth until raster exports can be generated with a vetted SVG renderer.
