# Tested & Trusted Cargo Site

Mobile-first marketing website for Tested & Trusted, a Kenyan clearing and forwarding company.

## Development

- `pnpm install` — install dependencies
- `pnpm dev` — start the Vite development server
- `pnpm lint` — run Oxlint
- `pnpm build` — type-check and create the production bundle
- `pnpm deploy` — build and publish the site to GitHub Pages

The production site is configured for the `/cargo-site/` GitHub Pages path.
